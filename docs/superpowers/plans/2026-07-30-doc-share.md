# 文档分享功能 实施计划（多 Agent 并行）

**Goal:** 单页面免登录分享链接，有效期 7 天（默认）/30 天/永久/自定义，含相对资源访问。

**Spec（含冻结的接口契约 §2）:** `docs/superpowers/specs/2026-07-30-doc-share-design.md`

## 分工

### Agent A — 后端（与 B 并行）
- Create: `server/services/shareStore.js`、`server/routes/share.js`、`test/share.test.js`
- Modify: `server/middleware/auth.js`（豁免 `/share/` 前缀）、`server/index.js`（挂载 share 路由——`/share` 挂在 requireAuth 之前；`POST /api/repos/:id/share` 走鉴权内路由）
- 要点：token `crypto.randomBytes(16).toString('hex')`；shares.json 0600、不存在视为空、读取时过滤过期并写回；res 端点限制在文档所在目录前缀内 + safeResolve 的 `.git` 拒绝；html 分享在 `<head>` 后注入 `<base href="/share/<token>/res/">`；无效/过期 token 一律 404 提示页（不区分）
- 测试：有效期各档、days 非法/缺 path 400、未登录创建 401、md/html/content/res 访问、res 越权 400、过期与无效 token 404、惰性清理

### Agent B — 前端（与 A 并行，只依赖契约）
- Modify: `public/app.js`（工具栏「分享」按钮 + 弹层）、`public/style.css`（弹层样式）
- Create: `public/share-view.html`
- 要点：弹层单选 7 天（默认）/30 天/永久/自定义天数（1–365 输入）；POST 契约接口后显示 `location.origin + url` 和复制按钮（clipboard API，失败降级显示文本）；share-view.html 从 `/share/<token>/content` fetch 渲染（marked + DOMPurify + hljs + github-markdown-light.css），相对图片/链接改写 `/share/<token>/res/...`，404 显示「链接已过期或不存在」

### Agent C — 集成与文档（A、B 完成后）
- 端到端冒烟（登录 → 建分享 → curl 全链路 → playwright 截图）
- README 增加「分享」一节
- 全量测试 + 提交推送

- A 只动 `server/`、`test/`；B 只动 `public/`——零文件交集
